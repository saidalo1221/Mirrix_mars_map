# AI usage

OpenAI Codex assisted with repository inspection, source verification, implementation, testing, and documentation for ARES Navigator V3. The main Codex agent coordinated the application and integration. Codex subagents handled bounded work on elevation data, imagery and scientific references, and submission materials. The team supplied the project requirements and owns the submitted claims and interpretation.

The starting workspace already contained an Ares Traverse prototype for the Curiosity boxwork region at Gale Crater. The team should disclose this baseline and distinguish it from the work added for ARES Navigator V3 when describing originality or eligibility.

The in-app route recommendation uses the application's numerical route calculations and selected mission settings. Codex assisted in writing the preprocessing scripts. The imagery and elevation inputs come from the products listed in the data documentation. Travel speeds, mission constraints, and observation plans are scenario assumptions. [Data sources](data-sources.md)

The 2026 Global Organizing Team allows AI tools and asks participants to disclose their use. Its guidance requires visible watermarks for AI-generated images or video and disclosure in descriptive text and metadata for AI-generated audio, code, or data. The Mars imagery credited in this project comes from mission datasets. [2026 AI guidance](https://github.com/nasa/spaceapps/discussions/1849)

We used OpenAI Codex and its subagents to assist with software development, data preparation, verification, and writing. ARES Navigator V3 extends an existing Ares Traverse prototype.
